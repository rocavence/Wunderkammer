## 1. 理念

Wunderkammer（珍奇室）是文藝復興時期收藏家的房間：書、標本、畫、地圖放在同一個空間，靠擺放與並置產生意義，而不是靠分類。這個 app 把同樣的做法搬到 Mac 上。

### 1.1 七條原則

1. **收藏不打斷**：收東西不跳對話框、不問放哪裡。收完在螢幕上方出現 1.6 秒的提示就結束。
2. **不先分資料夾**：側欄的分組都由系統產生（格式、分類、主題、顏色）。使用者自己建立的只有「釘選版」，而且排在最後。
3. **存的是代表，不是檔案**：檔案以參照方式收藏，只記路徑與 bookmark；圖庫只放縮圖、metadata 與網頁快照。需要時才複製一份進圖庫。
4. **理解在本機完成**：OCR、物件、顏色、相似、語意搜尋、提問，全部用 Apple Vision、NaturalLanguage、MobileCLIP 與 Foundation Models 在本機執行，不上傳任何內容。
5. **重新發現跟收藏一樣重要**：隨機、過去的今天、被遺忘的、足跡，讓舊收藏回到眼前。
6. **安靜的介面**：版面接近編輯刊物，介面只用一個重點色。介面不搶內容，只用無襯線字。
7. **每個改動都要驗證**：端對端自我測試直接操作 app 本身並截圖，不搶焦點、不動滑鼠。

## 2. 0.2.0 現況

### 2.1 三個空間

視窗頂端中間是三個分頁（`⌘1`–`⌘3`）。每個空間記得上次用的排法。

| 空間 | 英文 | 用途 | 排法 | 側欄 |
|---|---|---|---|---|
| 收藏 | Collection | 瀏覽與尋找 | 格狀、瀑布、時間軸 | 全部、格式、分類、主題、顏色、釘選版 |
| 漫遊 | Wunder | 重新發現 | 無限牆 | 全部、過去的今天、被遺忘的、足跡、隨機一件、主題、顏色 |
| 工作台 | Space | 自由擺放 | 畫布 | 同「收藏」 |

排法切換與該空間的工具都在畫面下方置中的浮動工具列，滑鼠移上去會出現名稱。

### 2.2 收藏方式

| 方式 | 操作 |
|---|---|
| 全域快捷鍵 | `⌘⇧C`：剛複製的東西優先，否則收最前面瀏覽器的目前分頁 |
| 截圖 | `⌃⌘⇧C` |
| 拖放、貼上 | 拖進視窗、拖到 Dock icon，或 `⌘V` |
| 選單列 | 拱門 icon，任何東西拖上去就收進目前的展室 |
| 分享選單、服務選單 | 任何 app 的「分享」或右鍵「服務」 |
| 瀏覽器 | Chrome、Zen、Firefox 擴充與書籤小程式 |
| Siri 與捷徑 | 收藏、搜尋、隨機、提問四個指令 |
| 監看資料夾 | 展室連結的資料夾有新檔案時自動收進來 |

### 2.3 展室

一台 Mac 可以有多個展室（Room），各自是獨立的圖庫。每個展室可以：

- 改名、自訂封面圖。
- **連結資料夾**：最多 3 個。資料夾裡現有的檔案會收進來；從資料夾移除的檔案，也會從展室移除。
- **收藏要收檔案**：展室自己開一個資料夾保存檔案（vault），與「連結資料夾」互斥。切換時會先詢問，同意後複製全部檔案，拒絕則取消。

設定都在展室卡片的背面，按「編輯」翻過去。

### 2.4 找到與理解

- `⌘K` 搜尋標題、檔名、網站、文字、圖中文字、物件、顏色、年份。中文查詢會對應到英文標籤。
- 語意搜尋：用描述找圖，需要先安裝本機 MobileCLIP 模型（約 106 MB）。
- 提問：搜尋框輸入問句後按 Return，由本機模型根據收藏回答。需要 Apple Intelligence。
- 右鍵「找相似的」；資訊側欄列出相關收藏與跨媒體關聯（同一個人、提到、同一個城市）。
- 網頁收藏後在背景保存整頁 PDF 與內文，網站關掉也看得到。

### 2.5 工作台

- 框選後拖出成新的一堆，堆與堆自動推開；手動連線。
- 按住 `Space` 拖曳平移，滾輪縮放。
- **分堆**：一顆按鈕，點開玻璃面板，可依格式、分類、主題、顏色分堆，順序與側欄相同。分不進去的放在「其他」。
- **儲存排列**：工具列右側三格，存目前的排列，點一下回到該排列。目前畫面符合的那一格以重點色標示。快捷鍵 `⌃1`–`⌃3` 回到、`⌃⇧1`–`⌃⇧3` 儲存。
- **重設擺放**：兩次確認，只清除位置，保留連線。

### 2.6 外觀與設定

- 設定沿用 Flione 版型：左側分頁，右側說明與控制項。
- 語言：繁體中文、English、日本語、한국어、Español、Português (Brasil)，切換後重新開啟。
- 外觀：跟隨系統、淺色、深色。
- 重點色：跟隨系統，或藍、紫、粉紅、紅、橙、黃、綠、石墨，預設橙。只影響選中狀態與重點，不改整體配色。
- Icon 全面使用 Iconoir（線寬 2.3），依視覺大小個別微調。
- App icon：米白底板（`#F3E9D9`）上的橙色拱門層疊卡片，主體占 78%。

## 6. Roadmap

### 6.1 原始三階段在 0.2.0 的狀態

使用者故事編號沿用原始的 User Stories Roadmap。

| 階段 | 範圍 | 0.2.0 狀態 |
|---|---|---|
| 一、基礎 | US-001～014：收藏、瀏覽、預覽、搜尋、零整理 | 14 項完成 |
| 二、理解 | US-201～211：語意搜尋、相似、OCR、主題、重新發現、提問 | 9 項完成，2 項部分完成 |
| 三、世界 | US-301～311：畫布、分群、足跡、跨媒體、同步、共享 | 5 項完成，1 項移除，5 項未做 |

部分完成與調整：

| 編號 | 項目 | 狀態 |
|---|---|---|
| US-204 | 辨識名字 | 部分：英文名字可以，中文人名與地名抓不到（系統不支援）；不再規劃 |
| US-209 | 自動連結 | 部分：資訊側欄的名字與網站可以點開，畫布上沒有自動連線的入口；不再規劃 |
| US-302 | 無限畫布 | 完成；0.2.0 移除「依關聯分堆」，改成四種分堆與儲存排列 |
| US-303 | 自動分群 | 完成，擴充為依格式、分類、主題、顏色 |
| US-304 | 文化圖譜 | 0.2.0 移除，使用者決定不保留 |

未做：US-306 個人化推薦、US-308 同步、US-309 行動版、US-310 共享、US-311 公開。
